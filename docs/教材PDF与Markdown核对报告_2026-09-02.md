# 教材 PDF ↔ Markdown 核对报告

- 核对日期：2026-09-02
- 核对对象：`raw_books/raw_sources/textbooks/` 下 4 个 PDF ↔ `materials/textbooks/` 下对应 Markdown
- 结论一句话：**B 书的 Markdown 是真的（97% 准确）；A1-A / A1-B / A2 三本的 Markdown 是整本虚构的。**

---

## 一、根因：PDF 有没有"文字层"

"文字层"= PDF 里存着可以直接复制的文字。有它，程序一秒读完；没有，只能靠 OCR 或人眼。

| 教材 | PDF 页数 | 文字层 | 来源 | 结果 |
| :-- | --: | :-- | :-- | :-- |
| Ελληνικά Β | 394 | ✅ 有 | 出版社原版电子书 | Markdown **真实** |
| A1-A | 91 | ❌ 无 | 手机拍照 | Markdown **虚构** |
| A1-B | 85 | ❌ 无 | 手机拍照 | Markdown **虚构** |
| A2 | 67 | ❌ 无 | 手机拍照 | Markdown **虚构** |

规律非常干净：**AI 读得到的就照实提取，读不到的就编。**

## 二、B 书：全书 385 页定量比对

B 书 PDF 的文字层用的是 2012 年的老式希腊字形编码（Mac Roman 字形位映射），
直接复制出来是 `£˘Ì¿Ì·È ﬁÙÈ ·›˙·ÌÂ` 这样的乱码，实为 `Θυμάμαι ότι παίζαμε`。

本次已完整破解该编码并写成解码器 `scratch/pdf_verify/decode.py`，
解码后全文存于 `scratch/pdf_verify/B_pdf_decoded.txt`（376 页老编码 + 19 页正常 Unicode）。

以解码后原文为准，逐页比对 Markdown：

| 指标 | 中位数 | 平均 |
| :-- | --: | --: |
| Markdown 准确率（MD 写的希腊词确实在原书该页） | **97.4%** | 92.9% |
| 原书覆盖率（原书该页的词被 MD 收录） | **97.8%** | 93.6% |

准确率分布（385 页）：≥80% 共 **347 页（90%）**；<20% 共 **0 页**。

**判定：B 书正文 Markdown 可信，可直接作为提词母本使用。**

## 三、A1-A / A1-B / A2：整本虚构

### 3.1 最硬的证据——三本 PDF 都是倒序拍摄，Markdown 却按正序编

实拍页与原书页的对应关系（已用 2 个独立采样点分别验证）：

| 教材 | 映射公式（PDF 第 N 页 → 原书页） | 实际覆盖原书 | 验证点 |
| :-- | :-- | :-- | :-- |
| A1-A | 原书页 = 10 + (91 − N) × 2 | 10–191 | p91→10-11、p11→170-171、p10→172-173 |
| A1-B | 原书页 = 6 + (85 − N) × 2 | 6–174 | p80→16-17、p40→96-97 |
| A2 | 原书页 = 16 + (67 − N) × 2 | 16–148 | p60→30-31、p30→90-91 |

而三本 Markdown 全部写成 `## Page 1` … `## Page 91` 并标注"原书第 N 页"，
即**默认 PDF 第 N 页就是原书第 N 页**——方向反了，起始页也错了。
这说明写 Markdown 的过程根本没有看过图。

### 3.2 逐页抽样比对（每一处都不符）

| 位置 | Markdown 声称 | PDF 实际（人眼核对） |
| :-- | :-- | :-- |
| A1-A p10 | 书写字母 σ / α；生词：云、葡萄、海盗、城堡、剑 | **Ενότητα 14「Στην παιδική χαρά 游乐场」原书 172-173 页**；动词 τρέχω/ανεβαίνω/κουνάω/κατεβαίνω |
| A1-A p11 | 字母 Γ γ / Ν ν；生词：巧克力、冰淇淋、吉他、架子鼓 | **Ενότητα 13 原书 170-171 页**；方位介词 μπροστά από / πίσω από |
| A1-A p45 | Γιώργος 与 Κώστας 的问候对话 | **桌游跨页 Επιτραπέζιο παιχνίδι**（无对话） |
| A1-B p40 | Γιώργος 与 Σοφία 离别去雅典的伤感对话 | **Ενότητα 27「Αγαπώ τα αθλήματα 我喜欢运动」原书 96-97 页**；运动装备词汇、红黄牌 |
| A2 p30 | ΚΑΤΑΝΟΗΣΗ **ΠΡΟΦΟΡΙΚΟΥ**（口语理解）；天气词汇 | **Ενότητα 4 原书 90-91 页**；ΚΑΤΑΝΟΗΣΗ **ΓΡΑΠΤΟΥ**（书面理解）+ 节日祝福语 |

注意 A2 那一处：栏目名对了一半，把"书面"写成了"口语"。
这是典型的"照着教材通用结构编"——**看起来很专业，具体内容全错**，比明显的胡话更危险。

### 3.3 单元主题也跟着错位

真实 **Ενότητα 27 = Αγαπώ τα αθλήματα（我喜欢运动）**，
而题库 JSON 里 U27 标的是「闲暇爱好与时态对比」，把"体育运动"安到了 U20。
