## 一、为什么要重建

原 AI 工具产出的三份 Markdown 教材（A1-A / A1-B / A2）**是编造的**，证据：

1. 这三个 PDF 是手机拍的照片，**没有文字层**，任何工具都不可能"读"出文字。
2. 三本书的照片**页序全是反的**（从后往前拍），而 Markdown 按正序编排 —— 说明它根本没看过图。
3. 5 处随机抽查，**5 处全部对不上**原书内容。

B 本（`Ελληνικά Β.pdf`）不同：它有文字层，只是用了 2012 年的旧字形编码。已解码，**385 页比对中位准确率 97.4%，是真的**。

## 三、页序公式（已双点验证）

| 书 | PDF 页数 | PDF 第 N 页 → 原书页码 | 覆盖 |
|---|---:|---|---|
| A1-A | 91 | `10 + (91−N)×2` | 原书 10–191 |
| A1-B | 85 | `6 + (85−N)×2` | 原书 6–174 |
| A2 | 67 | `16 + (67−N)×2` | 原书 16–148 |

## 四、核心方法：封闭词表反向搜索

**不要试图"读出整页课文"，只问"词典里的哪些词出现在这一页"。**

前者是识别问题（难，OCR 全文可信率只有 43–54%）；后者是在 3038 词封闭集合里做匹配（容错空间大得多）。

实测（A1-B 原书 96–97 页，"我喜欢运动"单元）：

| 指标 | 数值 |
|---|---:|
| 全文 OCR 可信识别率 | 43–54% |
| **封闭词表反向搜索 · 召回率** | **75–86%** |
| **误报率** | **2.8%**（且其中 `μπαμπάς`、`Άννα` 经查原文确实存在，实际更低） |

容错阈值按词长分级（短词必须近乎精确）：`≤4字→0, ≤6→1, ≤10→2, 更长→3`

## 六、已否决的两条路（别再试）

### 1. 编辑距离自动纠错 —— 危险，已废弃
把 OCR 出的词按最小编辑距离"修"成词典词，结果把**本来对的词改成不相干的词**：
```
Κώστα(人名)  → σωστά(正确的)     ❌
γράφεις(你写) → γραφείο(办公室)   ❌
έχει(他有)    → εκεί(那里)        ❌
```
根因：词典收原形，课文里全是变位形式。已改用 `scripts/ocr/morph.py` 的词尾规则还原。

### 2. 图像预处理 —— 无效
二值化 / 光照均衡 / 4 种 PSM 模式全试过，**可信词数稳定在 67 个左右纹丝不动**，只是噪声多少不同。调参已到顶。

## 七、踩过的坑

- **并行 OCR 时临时图片文件名撞车**：三本书的 `p10-10.png` 同名，互相覆盖删除，导致 50 多页 OCR 结果为空。已改成 `{book}_p{page}` 独立命名。**重跑前先 `find scratch/ocr_text -size -100c -delete` 清掉空文件。**
- `/tmp` 下的临时文件子进程读不到（沙箱限制），工作目录必须放项目内 `scratch/ocr_work`。
- tesseract 的 stderr 不是 UTF-8，`subprocess` 要加 `errors='replace'`。
- A1-A 前两页 `Malformed JP2`，pdftoppm 会警告但仍出图，不影响。

### A1-A / A1-B 单元边界的难点（保留记录，供日后再攻）
儿童版**没有页脚单元号**。单元号是左页左上角的**彩色徽章**（如 `Ενότητα 27`），
且**只出现在每个单元的第一页**，**颜色逐单元变化**（27 是粉色，19/20/29 不是）。

已试过并失败的：
- 纯色块计数（`badge.py`）→ 误报多，因为徽章颜色不固定
- 亮度定位书本区域后裁顶部（`badge3.py`）→ 定位框算错，裁出空白
- 400dpi 全页 psm11 重扫 → 约 70 秒/页，176 页要 3 小时，太慢已放弃

**当前方案**（`scripts/ocr/badge_scan.py`，正在跑）：用 `pdftoppm -x -y -W -H`
只渲染每页左上角 48%×48% 区域（面积 1/5，快 5 倍），对该区域同时跑 psm 11 与 psm 6，
正则容错匹配 `Ενότητα\s*N`。

**已知真值锚点**（用来校验结果）：
| 书 | 书页 | 单元 | 来源 |
|---|---:|---:|---|
| A1-A | 132 | 9 | 全页 OCR |
| A1-B | 28 | 19 | 全页 OCR |
| A1-B | 34 | 20 | 全页 OCR |
| A1-B | 96 | 27 | **实拍图人工确认** |
| A1-B | 114 | 29 | 全页 OCR |
> 从 20@34 到 27@96 是 7 个单元跨 62 页（8.9 页/单元），27@96 到 29@114 是 2 个单元跨 18 页（9 页/单元），**间距自洽**。

**如果徽章扫描仍失败的退路**（不违反红线）：
A1 两本改为**按跨页出数据**（每个跨页一份真词表，100% 有据），
单元归属留空。这与 P1 家长端改造方向一致——那个设计本来就是把操作单位
从"单元"改成"这次课讲到哪几页"，家长知道页码，不需要单元号。
