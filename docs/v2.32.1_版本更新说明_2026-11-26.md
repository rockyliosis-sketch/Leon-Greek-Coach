## 一、三大区块选书升级：放大书皮二次确认 + 选错随时可换/重选

### 痛点背景
孩子在三大攻坚区块选择电子课本或练习册时，缩略封面较小、希腊语课本各册（`Τεύχος Α / Β / Γ`）外观接近，容易看错封皮点错书；且此前代码中 `InteractiveTextbookViewer.tsx` 一旦收到 `explicitBookId` 就会把候选书列表收缩为 1 本，导致选书栏直接隐藏，孩子选错后无法重新选书或移除该书。

### 核心改进
1. **放大书皮二次确认弹窗**（`frontend/src/components/InteractiveTextbookViewer.tsx`）
   - 选书栏缩略封面加大并配放大镜角标，点击任意候选书封皮不再直接锁死，而是先弹出居中 **放大封面核对弹窗**（高清大图封皮 + 中文书名 + 希腊语原名 + 总页数 + 册号核对提示）；
   - 提供 **「✅ 就是这本，确认选书」** 与 **「↩️ 选错了，换一本」** 两个清晰大按钮；
   - 已选课本封皮右下角新增 **「🔍 放大」**，随时可点击放大与手里纸质书对照。
2. **随时可换书 / 清空重选**（`frontend/src/components/InteractiveTextbookViewer.tsx`、`frontend/src/pages/student/DailyMissionHall.tsx`）
   - 彻底修复 `candidates` 选一次就锁死隐藏选书栏的问题；
   - 在已选课本顶部新增 **「🔄 换一本书」** 与 **「🗑️ 选错了·重选」** 按钮；
   - 区块三切换练习册或预习科目下拉框时，自动清空旧的 `bookId`，杜绝旧书残留。

## 二、Gemini AI 分级思考优化 + 根治小模型复读刷屏与 Token 异常消耗

### 痛点背景
Leon 在区块三点查课本词 `ρίξει` 时，轻量化模型 `gemini-3.5-flash-lite` 因接口未设置 `maxOutputTokens` 上限、且提示词包含口语鼓励风格，触发了中文感叹词复读死循环（`加油！欧啦！冲鸭冲冲冲…`），单次点击即异常消耗数千 Tokens。

### 核心改进
1. **分级思考与硬性 Token 封顶**（`api/textbook-assist.mjs`、`api/translate.mjs`）
   - **纯查词 / 批量翻译**（录词框一键填中文 & 课本点词精讲）：`gemini-3.5-flash-lite` + `thinkingLevel: 'minimal'` + `temperature: 0.1` + 硬性封顶 `maxOutputTokens: 320`（批量翻译按词数动态封顶），线上实测 `ρίξει` 仅消耗 **488 Tokens**；
   - **深度教学任务**（课前预习导读 `preview_guide`、重点提炼与随堂出题 `review_coach`、练习册讲题 `explain_exercise`）：**保持 `gemini-3.8-flash` + `thinkingLevel: 'low'`** + `maxOutputTokens: 2048`，确保分析与出题深度。
2. **提示词收紧 + 服务端复读检测自动熔断**
   - 明确禁止任何网络口水话与感叹词堆砌，`usageTip` 严格限制在 1 句 60 字以内；
   - 服务端新增 `hasDegeneration` 复读检测，一旦发现连续复读或超长输出立即熔断，并自动切换 `gemini-3.8-flash` 重试。
3. **前端损坏缓存自愈**（`frontend/src/lib/textbookService.ts`）
   - `peekTextbookAssistCache` 读取旧缓存时自动跳过含复读或超长的损坏词条，刷新页面再次点词即自动覆盖为干净释义。
