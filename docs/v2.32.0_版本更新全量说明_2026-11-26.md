## 一、18 册电子互动课本、矢量重提与专业版式精排（`v2.30.0` – `v2.31.0`）

### 1. 全套书目与纸质页码 1:1 精确映射
- **公立学校教材与练习册（16 册 · 1,560 页）**：
  - **希腊语语言（`Γλώσσα` 三、四年级共 10 册）**：每学年含课本 `Α / Β / Γ` 三册 + 练习册 `Τετράδιο Εργασιών Α / Β` 两册，精确编码跨册单元映射（如课本 `Β` 册前两单元对应练习册 `Α` 册末尾页码），选定课本页码后可一键展开对应练习册页码。
  - **历史（`Ιστορία` 三、四年级共 4 册）**：课本 + 练习册双册配对，打开对应课本页码时自动浮现 **「🏛️ 去听对应历史故事音频」** 直达入口，无缝衔接历史故事馆 91 课双语长音频。
  - **英语（`Αγγλικά` 四年级共 2 册）**：课本 + 练习册完整收录，攻克教育部老版 PDF `Windows-1253 / MacGreek / Glyph-ID` 混排乱码。
- **私教核心教材（2 册 · 428 页）**：
  - 收录《Ελληνικά Α’》（A2 核心课本）与 **《Ελληνικά Β’》（393 页全书改由原版矢量 PDF MacGreek 字形直接解码重提）**，彻底根治旧 OCR 错字（如 `Δον→Τον`、`μγαίνεις→Βγαίνεις`）与机械 `#` / `**` / `* •` 裸露符号；全库 18 册通过严苛门禁校验（`PUA = 0`、`soft_hyphen = 0`、控制字符 `= 0`）。

### 2. PDF 几何结构重排与生动模块化栏目彩卡
- **自然段智能重排与跨行断词拼回**：自动识别并拼接 PDF 软连字符（`U+00AD`，如 `μι­/κρά → μικρά`）与行尾硬连字符（如 `ανα-/πνοή → αναπνοή`），消除碎行断句，确保手指点词查义永远点到完整单词。
- **版式组件还原**：支持波浪弧形课文标题还原、蓝边诗歌分节、带人物名牌的对话行、真实斑马纹网格语法表、填空题紫色动词原形提示 `______ (τρώω)`，以及独立剥离到底部的琥珀色 **「📌 页边小词典与旁注」** 专属卡片。
- **模块化 Emoji + 中文导语主题彩卡**：自动识别教材原始栏目并生成带一句中文阅读指导的视觉卡片，告别干巴巴文字堆砌：
  - 📘 **`Ενότητα` 单元导览横幅**（靛蓝渐变头卡）
  - 🔍 **`Για δες / Γραμματική` 语法放大镜**（紫罗兰主题卡 + 阳/阴/中性三列对照格 + 💬 例句气泡）
  - 🗣️ **`Πώς το λένε;` 地道口语表达框**（青绿会话卡）
  - 🗂️ **`Λέξεις, λέξεις...` 生词宝盒**（琥珀胶囊词群卡）
  - ✅ **`Σωστό ή λάθος` 对错判断卡** / 🙋 **`Απαντάω` 课堂问答卡** / 📜 **`Παράθεμα` 历史史料卡**

### 3. 默认收起手风琴 + 右侧悬浮查词挂件
- **每页默认折叠收起**：打开多页范围时，每一页纸质书默认以紧凑手风琴条呈现（显示印制页码、首句预览及本页已圈重点词数），顶部配「全部展开 / 全部收起」开关，页面清爽不冗长。
- **计时器正上方右侧悬浮查词小窗**：在任意一页点选不懂的希腊语单词，无需翻回页面最上方——右侧固定悬浮小窗（精确定位于全局浮动计时钟正上方，预留 `216px` 安全净空，绝不遮挡计时器）即刻展示发音按钮、中文释义、词根原形与词形变化说明，支持原地一键 **「⭐ 圈为重点加入生词库」**（自动汇入 `/practice` 做题区 8 大题型与艾宾浩斯复习），也可点 **「⬆️ 顶部详情」** 平滑滚回顶部完整精讲面板。

## 二、全站 Gemini AI 伴读助教、云端缓存与实时 Token 看板（`v2.29.0` – `v2.32.0`）

### 1. 两大 Vercel Serverless AI 接口（密钥安全隔离）
- **`POST /api/translate`（生词极速词典接口）**：用于录词框 **「✨ 一键自动填中文」**。前端优先检索本地 `5,000+` 课本与单词表词库（0 延迟、0 Token 消耗），仅将未命中词批量提交 Gemini 词典模式（单次最多 40 词），自动完成词形辨析与 iPad 语音识别漏字纠偏。
- **`POST /api/textbook-assist`（课本伴读与讲题接口）**：优先调用 `gemini-3.5-flash-lite`（自动回退 `gemini-3.8-flash` 低思考延迟模式），提供 4 大结构化教学能力：
  1. **`word` 语境精讲**：结合当前课文原句给出精准中文义项、标准词典原形（Lemma）、人称/格数变化拆解与简短双语例句；
  2. **`preview_guide` 预习启发**：生成 30 秒中文导读、建议抄在纸质书上的重点词、边读边想的启发问题，并在孩子提交预习总结后解锁 3 条课文核对要点；
  3. **`review_coach` 重点提炼与随堂小测**：提炼本页 3 条核心语法/课文重点，并现场出 **3 道带解析的随堂选择题** 检验吸收度；
  4. **`explain_exercise` 题干翻译与分步讲题**：针对课后练习与配套练习册（Τετράδιο Εργασιών），逐题翻译希腊语题干要求并拆解做题步骤与语法坑点，**严守教学红线绝不直接代写答案**。

### 2. 全站官方 Gemini 标识 + 面板自由收起 + 跨设备云端持久缓存
- **官方品牌标识（`GeminiBadge.tsx`）**：全站 7 处调用 Gemini 模型的按钮与结果面板统一展示 Google Gemini 官方四芒蓝紫渐变星徽标与标识说明。
- **可收起面板 + 双层持久缓存（`aiAssistCache`）**：
  - 重点小测、题干讲题、预习导读面板右上角均配备 **「收起 ▲ / 展开 ▼」** 切换键与可选 **「重新生成」** 按钮；
  - 任何一页生成过一次后，结果自动同步保存在本地 `localStorage` 与云端 Firestore（`textbook_preferences.aiAssistCache`）。刷新网页、隔天复看或换设备打开同一页时直接显示 **`✓ 已有重点与小测（展开 ▼）`**，**0 API 调用、0 Token 消耗**瞬间展开。

### 3. 首页「✦ 网站已接入 Gemini AI · 今日实时 Token 消耗」磨砂玻璃卡（`v2.32.0`）
- **黄金位置并排呈现**：安放在首页蓝色欢迎横幅中「当前段位」磨砂玻璃卡正右侧，等高同材质半透明圆角设计，在桌面端与 iPad 横竖屏下均舒展对称，既不挤占顶部白色导航栏，也不遮挡右侧希腊国旗背景。
- **官方 `usageMetadata` 精确统计 + 跨设备同步**：后端实时提取 Google Gemini API 原生返回的 `promptTokenCount`、`candidatesTokenCount`、`thoughtsTokenCount` 与 `totalTokenCount`，按希腊当地日期自动累加至 Firestore `textbook_preferences.geminiUsageByDate`（保留近 30 天明细）：
  - 主行实时显示：**`今日 X,XXX Tokens`**；
  - 副行实时显示：**`调用 M 次 · 云端已缓存 K 页`**；
  - 悬停/长按卡片可查看今日输入 Prompt Tokens 与输出 Output Tokens 拆分明细。

  - Step 2 执行三年级《语言 + 练习册》跳单元强制闯关；
  - Step 3 支持孩子**自主选择明日科目与页码**，结合 Gemini 启发问题或自己独立挑重点词、写一句预习总结，学习日报自动附带 **「📖 课本该页真实内容对照」** 供家长一秒核验。
