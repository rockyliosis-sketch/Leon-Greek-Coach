## 内容抽验

- 第 1 课听阿特拉斯撑天，再看地图册与泰坦水泥厂的练习册联想。确认正文的希腊语只在首次出现时插播，片尾再统一领读。
- 第 2 课从硬币上的鹰和三叉戟辨别宙斯与波塞冬。第 3 课从练习册所示机构标志找出谷物、智慧与信使的联系。
- 第 4 课区分课文的大陶罐和课堂活动的盒子，再让孩子挑一种困难，试着用一句希腊语提出办法。
- 希腊语轨默认显示全文与当前段，可展开逐段中文大意。21 道自选活动包含选择、判断、配对和开放表达。点击词卡播放的是预生成的希腊语录音。

## 真机体验

请分别用 Leon 的 iPad Safari 和主屏幕入口验收，记录 iPadOS 版本和使用的扬声器或耳机。

1. 中文选 1.15×，希腊语选 0.85×。各听一小段，刷新后切换，检查位置与语速。
2. 从第 1 课末尾开始连播并锁屏。确认锁屏显示封面、标题和「希腊历史故事馆」，能控制暂停、快退、快进、切集，且第 2 课能自动出声。
3. 选「播完本集」，听最后 3 秒的音量并确认停播。再选 10 分钟，在锁屏下跨集收听，检查到点与淡出的实际听感。不同系统可能限制网页调整音量。
4. 打开睡前模式，横竖屏各试一次。点读词卡后听故事是否回到原处。白天可试中文提示、配对、开放表达和跳过。

## 工程复现

剧本与课件在 `frontend/src/data/history/g3_unit1.json`，四份可读剧本在 `materials/history_scripts/`。音频与词卡在 `frontend/public/audio/history/`。生成器依赖 `edge-tts`、`ffmpeg` 和 `ffprobe`。

```sh
python3 scripts/generate_history_audio.py --lesson g3_u1_l1
npm --prefix frontend run build
```

本阶段只制作三年级第一单元。下一单元等待家长和 Antigravity 验收听感、难度与真机播放。
